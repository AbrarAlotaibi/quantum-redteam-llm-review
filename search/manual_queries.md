## 1. IEEE Xplore: Command Search

Go to Advanced Search, then Command Search, and paste each string. Each term is searched in `"Document Title"` OR `"Abstract"` (title and abstract). IEEE Xplore's help states a maximum of **25 search terms per search clause**. Each term appears twice (once for title, once for abstract), so the full strings are split into numbered sub-queries of at most 25 terms. Together the sub-queries cover the full query. Run each one, export the results, and deduplicate by DOI. Set the year range (2018-2026) with the Year filter on the results page for S2-S4. IEEE has no computer-science subject filter, since IEEE content is essentially computing and engineering. If you want a narrower set for S3 and S4, apply the Topic filter (for example, Computing and Processing) and note that you did.

Record the count of each sub-query, then export and deduplicate across the sub-queries by DOI. The sum of the sub-query counts overstates the unique total.
